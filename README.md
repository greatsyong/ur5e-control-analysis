# UR5e Control Analysis and ROS2 Validation

End-to-end UR5e control study covering analytical modeling, controller design, numerical cross-validation, and ROS2 / NVIDIA Isaac Sim runtime validation.

The project is organized into two stages:

```text
Part 1
Analytical modeling
        ↓
Controller design
        ↓
Python / C++ cross-validation
        ↓
Robustness analysis

Part 2
ROS2 controller implementation
        ↓
Isaac Sim integration
        ↓
Runtime validation
        ↓
Experimental CSV results
